# Secrets Integration Harness

Status: `done`
Suggested branch: `test/secrets-integration-harness`
Priority: `high`

## Goal

Verify the hand-off between secrets managers (`sops-nix`, `agenix`) and our
modules by evaluating a real multi-module configuration.

## Scope

- Use the actual `sops-nix` and `agenix` modules (via flake inputs) in a test.
- Verify that `services.attic-client.manualTokenPath` correctly points to the
  secret path generated by these modules.
- Ensure Home Manager token substitution works with paths derived from secrets.
